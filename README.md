# AutoDART 설치 파일

DART(금융감독원 전자공시)·SEC EDGAR 공시 재무 데이터를 리서치용 엑셀로 만들어 주는 Windows 프로그램의 **설치 파일 배포용 저장소**입니다. 소스 코드는 이곳에 없습니다.

## 다운로드

[최신 버전 받기 (Releases)](https://github.com/newkim-ux/autodart-releases/releases/latest) → Assets의 `AutoDART-Setup-x.y.z.exe`

- Windows 10/11 64비트 전용, 관리자 권한 없이 내 계정에만 설치됩니다.
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요 (코드 서명이 없는 개인 프로그램이라 뜨는 경고입니다).
- 본인의 [OpenDART](https://opendart.fss.or.kr) 인증키와 이메일(미국 SEC 조회용)이 필요합니다. 키는 이용자 PC에만 암호화되어 저장됩니다.
- 설치한 뒤에는 새 버전을 프로그램이 자동으로 받아 두고, 화면 오른쪽 위 [재시작하여 업데이트]로 적용합니다.

공시 데이터는 각 회사가 제출한 것이며 정확성을 보장하지 않습니다. 투자 판단의 책임은 이용자에게 있습니다.
